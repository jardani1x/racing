# Verification reports

Store human-readable summaries that point to generated artifacts under the build/test system. Reports must identify build ID, commit/changelist, hardware, map, car/tune, browser/network profile, commands, pass/fail status, artifact paths, and approvers.

Suggested reports:

- build-and-package;
- gameplay correctness;
- vehicle manoeuvres and soak;
- screenshot comparison;
- Unreal Insights performance;
- Pixel Streaming latency/reliability;
- security/operations;
- IP/provenance audit;
- final A-H quality-gate report.
